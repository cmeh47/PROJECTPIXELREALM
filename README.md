# Project Pixel Realm

Working name. A cozy, 4-player co-op pixel RPG for iOS and Android.

Friends share a base, gather resources, take NPC quests and clear dungeons together, live or at different times. Combat is reactive turn-based: timed strike runes, dodges, parries, counters and attack chains.

## Status

Early development, milestone 1: combat animation storyboards, then a combat-feel prototype.

## Stack

- **App:** Expo + React Native, with React Native Skia for the game scenes and Reanimated for animation
- **Backend:** Supabase (sign-in, Postgres, Realtime for the shared hub and live dungeons)
- **Art:** Aseprite
